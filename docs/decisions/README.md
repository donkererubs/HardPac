# Architecture Decision Records

An ADR captures a significant decision and its context in one page, so future
sessions (human or agent) don't re-litigate it.

**Format:** one file per decision: `NNNN-short-title.md` (zero-padded sequence).
Each ADR follows this template:

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by NNNN

## Context
What is the situation that forces this decision?

## Decision
What did we choose?

## Consequences
What becomes easier / harder because of it?
```
